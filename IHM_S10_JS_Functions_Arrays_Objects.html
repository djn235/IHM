01
FunctionsDeclaration, expression and arrow syntax




A function is a named, reusable block of instructions that receives parameters, performs a computation and may return a value. Functions are the primary tool of abstraction: they give a name to a piece of logic, isolate it, and allow it to be tested independently.




FormSyntaxCharacteristics


Declarationfunction vat(net) { return net * 0.19; }Hoisted: callable before its definition


Expressionconst vat = function (net) { ... };Not hoisted; a value assigned to a binding


Arrow functionconst vat = (net) => net * 0.19;Concise; implicit return for a single expression; no own this




    

  • Default parameters: function vat(net, rate = 0.19) applies when the argument is undefined.
    • 

  • Rest parameters: function sum(...amounts) collects any number of arguments into an array.
    • 

  • Pure functions: their result depends only on their arguments and they cause no side effect. They are predictable and easy to test; prefer them for business calculations.
    • 







Scope and closuresA function has access to the variables of the scope in which it was defined (lexical scope), even after that outer scope has finished executing. Such a function, together with the environment it captures, is a closure. Closures enable factories such as makeTaxCalculator(0.19), which return functions configured once and reused many times.





02
ArraysOrdered collections




An array is an ordered, zero-indexed list of values: const sales = [120, 135, 98]. Its length property gives the number of elements; sales[0] is the first and sales[sales.length - 1], or sales.at(-1), the last. Methods divide into those that mutate the array in place and those that return a new value, leaving the original untouched.




Mutating
push pop unshift shift splice sort reverse


Non-mutating
slice concat includes indexOf find findIndex join map filter toSorted




Array laboratory


Apply methods to the array and observe indices, return values and the length.








The sort trapWithout a comparator, sort() converts elements to strings and orders them lexicographically: [35, 8, 120, 15] becomes [120, 15, 35, 8]. For numbers, always pass (a, b) => a - b (ascending) or (a, b) => b - a (descending).

Declarative Array MethodsforEach, map, filter, reduce, find, some, every




Higher-order array methods take a callback function and apply it to every element, replacing explicit loops with a description of what to compute rather than how:




MethodReturnsBusiness example


map(fn)A new array of the same length, each element transformedPrices including VAT


filter(pred)A new array of the elements for which pred is truthyProducts in stock


reduce(fn, init)A single accumulated valueCart total, maximum, grouping


find(pred)The first matching element, or undefinedThe product with a given code


some / everyA boolean: at least one / allIs any item out of stock?


forEach(fn)undefined (side effects only)Logging, updating the display

How reduce worksreduce(fn, init) calls fn(accumulator, element) for each element, the accumulator starting at init and taking, at each step, the value returned by the previous call. Always provide the initial value: without it, reduce on an empty array throws a TypeError.





04
ObjectsProperties, methods, destructuring and JSON




An object groups named properties describing one entity: { code: "P-101", name: "Laptop", price: 95000 }. Properties are accessed with dot notation (p.price) or bracket notation when the key is computed (p[field]). A property whose value is a function is a method; inside it, this refers to the object on which the method was called.


    

  • Destructuring: const { name, price } = product; extracts properties into variables; const [first, second] = list; does the same for arrays.
    • 

  • Spread: { ...product, price: 90000 } creates a modified copy without altering the original, the basis of immutable updates.
    • 

  • Introspection: Object.keys(), Object.values(), Object.entries() turn an object into arrays that can be iterated.
    • 

  • Optional chaining: customer.address?.city returns undefined instead of throwing when address is absent.
    • 









JSON: the lingua franca of data exchange


JavaScript Object Notation is a textual format derived from object literals, used by virtually every Web API. JSON.stringify(value) serialises a value into a string (to send it to a server or store it in localStorage); JSON.parse(text) performs the reverse. JSON requires double-quoted keys and strings, and cannot represent functions, undefined or dates (which become strings).






ClassesWhen many objects share the same structure and behaviour, a class defines their template: class Product { constructor(name, price) { this.name = name; this.price = price; } priceWithVat() { return this.price * 1.19; } }, instantiated with new Product("Laptop", 95000). Classes are syntactic sugar over JavaScript's prototype mechanism.

Practical ExercisesAbstract, transform, aggregate


EX 01
A library of financial functions
Foundational


Write and test the following functions:


  • vat(net, rate = 0.19) as an arrow function returning the VAT rounded to two decimals.
  • gross(net, rate), which reuses vat.
  • formatDZD(amount), which returns a string formatted with Intl.NumberFormat.
  • sumAll(...amounts), which accepts any number of amounts.






EX 02
Analysing monthly sales
Intermediate


Given an array of twelve monthly revenue figures, compute with array methods only (no explicit loop): the annual total, the monthly average, the best month (name and value), the months above the average, and whether every month exceeded 300 000 DZD.






EX 03
A shopping cart object
Intermediate


Create a cart object with an items array and the methods add(product, qty) (increase the quantity if the product is already present), remove(code), count() and total(). Test it with three products and display the contents with console.table.






EX 04
Grouping and ranking transactions
Advanced


From an array of transactions { id, category, amount, date }:


  1. Use reduce to build an object giving the total amount per category.
  2. Convert it with Object.entries into an array sorted by descending total.
  3. Display the top three categories with their share of the overall total as a percentage.
  4. Return the JSON string of the report.
