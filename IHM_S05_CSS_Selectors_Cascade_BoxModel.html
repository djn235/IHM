Anatomy and Integration of CSSRules, declarations and stylesheets




A stylesheet is an ordered set of rules. Each rule consists of a selector, which determines the elements concerned, and a declaration block containing property: value pairs separated by semicolons.

}

Internal stylesheet<style>...</style> in headAcceptable for a single page or prototypes (as in this lecture's examples).

03
The Cascade, Specificity and InheritanceResolving conflicting declarations




When several declarations assign a value to the same property of the same element, the cascade algorithm selects a single winner by comparing, in this order:


    

  1. Origin and importance: user-agent styles < author styles < author !important (with transitions and animations at specific levels).
    2. 

  2. Cascade layers (@layer), when used: later layers win over earlier ones.
    3. 

  3. Specificity: a triple (a, b, c) compared lexicographically, where a counts ID selectors, b classes, attributes and pseudo-classes, and c types and pseudo-elements. Inline styles outrank all selectors.
    4. 

  4. Order of appearance: if everything else is equal, the last declaration wins.
    5. 



Lexicographic comparison(1,0,0) beats (0,12,0): a single ID outweighs any number of classes. :where() contributes zero specificity, whereas :is(), :not() and :has() take the specificity of their most specific argument. The universal selector and combinators count for nothing.






Inheritance


Some properties, mainly typographic ones (color, font-family, font-size, line-height, text-align), are inherited by descendants that receive no value of their own. Box-related properties (margin, padding, border, width, background) are not. The keywords inherit, initial, unset and revert control this behaviour explicitly. Note that an inherited value always loses to any declaration targeting the element directly, regardless of specificity.






On !importantIt short-circuits the specificity contest and leads to escalation (overriding an !important requires another). Reserve it for utility classes and for overriding third-party styles you cannot modify.

05
The Box Modelcontent, padding, border and margin




Every element generates a rectangular box composed of four concentric areas: the content, the padding (inner spacing, which takes the background), the border, and the margin (outer, transparent spacing). The box-sizing property determines what width and height measure:


  • content-box (default): width applies to the content only; padding and border are added to it.
  • border-box: width includes padding and border; the content shrinks accordingly. Universally adopted in professional projects.


Interactive box model













margin










Margin collapsingThe vertical margins of adjacent block boxes in normal flow collapse into a single margin equal to the larger of the two: a paragraph with margin-bottom: 30px followed by one with margin-top: 20px are separated by 30px, not 50px. Horizontal margins, and margins inside flex or grid containers, never collapse.


Investigating with DevToolsPress F12, select an element, and open the Styles and Computed panels: overridden declarations appear struck through, and the box-model diagram displays the exact dimensions. This is the primary diagnostic tool for any CSS problem.

EX 04
Box arithmetic for a product card
Advanced


A product grid requires each card to occupy exactly 300px horizontally including its border, with 20px of padding and a 2px border; cards are separated vertically by 24px.


  1. Under the default box sizing, what width must be declared? What is the content width?
  2. Rewrite the rule using border-box. What is the content width now?
  3. Card A has margin-bottom: 24px and card B, below it, has margin-top: 16px. What is the vertical gap, and why?




1. content-box: width = 300 - 2×20 - 2×2 = 256px; content width = 256px.
2. border-box: width = 300px; content width = 300 - 40 - 4 = 256px (same result, but no arithmetic for the author).
3. Gap = max(24, 16) = 24px: adjacent vertical margins in normal flow collapse.
