A
Part A: Guided ApplicationsExercises 1 and 2


Method for every application(1) list the data the application must remember (the state); (2) write the pure functions that compute derived values; (3) write render(), which rebuilds the view from the state; (4) connect the events, which only modify the state and call render(). Each solution is a single file you can copy, run and extend.


EX 01
A live currency converter
Intermediate30 min


Build a converter between DZD, EUR, USD, GBP and TND using the fictitious rates of Lab 10 (value of one unit in DZD: EUR 150, USD 135, GBP 175, TND 43).


  • An amount field and two currency selects; the result updates as the user types, formatted with Intl.NumberFormat.
  • A "Swap" button exchanging the two currencies.
  • A table of the five rates, with the row of the current source currency highlighted.
  • A "Save" button adding the conversion to a history of the last five conversions, persisted in localStorage and restored on reload.
  • Invalid amounts (empty, negative) display a message instead of a result.






EX 02
A self-assessment quiz
Intermediate35 min


Build a five-question multiple-choice quiz on the IHM module. Requirements:


  • questions stored in an array of objects { question, options, answer, explanation };
  • one question at a time, options rendered as radio buttons in a fieldset; the "Validate" button is enabled only once an option is chosen;
  • after validation, the correct option is marked, the explanation shown and a "Next" button appears; a progress bar shows the current position;
  • at the end, the score, a mention, and a review list of the questions answered incorrectly, plus a "Restart" button.

Part B: Business ToolsExercises 3 and 4


EX 03
An invoice generator
Advanced40 min


Build an invoice editor for a small enterprise:


  • a header with the customer's name and an invoice number generated automatically (format INV-2026-0001, incremented and persisted);
  • a table of lines (description, quantity, unit price, line total) with "Add a line" and per-line "Remove" buttons, handled by event delegation;
  • a global discount (0 to 30%) and a VAT rate selector (0%, 9%, 19%);
  • totals (net, discount, taxable amount, VAT, total due) recomputed on every input;
  • a "Print" button calling window.print(), with a print stylesheet hiding all controls.




Check with the default lines2 × 15 000 + 1 × 58 800 = 88 800 net; discount 5% = 4 440; taxable 84 360; VAT 19% = 16 028.40; total due 100 388.40 DZD.




EX 04
A sortable, searchable, paginated data table
Advanced40 min


Display a product catalogue of 23 items (generated in the solution) in a table component:


  • clicking a column header (Code, Name, Category, Price, Stock) sorts by that column, ascending then descending, reflected with aria-sort; strings are compared with localeCompare, numbers numerically;
  • a search field filters on code and name;
  • pagination of 5 rows per page with "Previous" / "Next" buttons, a "Page x of y" indicator and correct disabling at the ends; changing the search returns to page 1;
  • rows whose stock is below 5 are highlighted and labelled "Low stock" in text.









C
Part C: Capstone ApplicationsExercises 5 and 6


EX 05
An inventory dashboard
Advanced45 min


Build the inventory dashboard of a pharmacy wholesaler:


  • KPI tiles: number of products, total stock value, number of products below their reorder threshold;
  • a horizontal SVG bar chart of stock value by category, with a text alternative;
  • a table of products below threshold, with the quantity to order (threshold × 2 − stock);
  • a "Stock movement" form (product, in/out, quantity) that refuses an outgoing quantity greater than the stock, updates everything, and logs the movement in a history list;
  • persistence of the products and history in localStorage, and a "Reset demo data" button.






EX 06
A mini CRM
Advanced50 min


Build a contact manager for a sales team:


  • contacts { id, name, company, email, phone, status } where status is Lead, Prospect or Customer;
  • a form to create a contact, and the same form reused to edit one (an "Edit" button fills it; the submit label changes to "Save changes"; a "Cancel" button resets it);
  • delete with a confirmation dialog;
  • search by name or company, filter by status, and counters per status;
  • persistence in localStorage and export of the visible contacts as CSV;
  • all actions announced in a live region; focus moved sensibly after each action.
