EX 01
The skeleton from memory
Foundational10 min


Without looking at your notes, write the complete skeleton of about.html, the "About us" page of the start-up Atlas SME Solutions (Kolea, Tipaza). Requirements:


  • Document type declaration, root element in English.
  • Five metadata items: encoding, viewport, description (at most 155 characters), author, title following the pattern "Page | Brand".
  • A body containing a single h1, a paragraph and a comment marking the end of the main content.


Self-check: paste your code into validator.w3.org ("Validate by Direct Input") and obtain zero errors.




Common mistakesPlacing meta charset after title; writing lang="eng" (the value is a BCP 47 tag: en); a description longer than about 155 characters, which search engines truncate.




EX 02
Reconstructing the document outline
Foundational15 min


The following lines are the titles of a page of the faculty's annual report, listed in reading order with their logical level given in brackets. Mark them up with the correct heading elements, each followed by a short paragraph, so that the document outline is valid (one h1, no skipped level).






Rule appliedThe level of a heading expresses its depth in the outline, not its visual size: "Students" and "Research" are siblings of "Teaching" (level 2), and "Doctoral programmes" returns to level 3 under "Research". Inspect the outline with a browser extension such as "HeadingsMap".

EX 05
Displaying code as text
Intermediate15 min


A tutorial page must show the following snippet to readers exactly as written, preserving indentation, without the browser interpreting it:




Write the markup that displays it inside a figure with the caption "Listing 1: a price label", using the appropriate elements and character references. Then explain why &amp; is needed in the URL of a link such as catalogue.php?cat=it&sort=price.




Explanationpre preserves whitespace and code marks the content as computer code. Every < must be written &lt; (and > as &gt; for symmetry), otherwise the parser opens a tag. In an attribute, a raw & followed by letters may be parsed as the start of a character reference (&sort is not one, but &copy= would be); writing &amp; is always unambiguous.
