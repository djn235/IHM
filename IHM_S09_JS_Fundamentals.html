01
JavaScript in the BrowserEngine, loading and the console




JavaScript is a high-level, dynamically typed, interpreted (and just-in-time compiled) language, standardised by Ecma International under the name ECMAScript. In the browser, a JavaScript engine (V8 in Chrome and Edge, SpiderMonkey in Firefox, JavaScriptCore in Safari) executes scripts, which access the page through the DOM and the other Web APIs.

Variables and Scopeconst, let, var




A variable is a named binding to a value. Modern JavaScript offers two declarations, plus a legacy one:




constletvar (legacy)


ReassignmentForbiddenAllowedAllowed

Before declarationReferenceError (temporal dead zone)ReferenceError (temporal dead zone)undefined (hoisted)


Redeclaration in same scopeForbiddenForbiddenAllowed (error-prone)




Professional ruleDeclare everything with const by default, and switch to let only when the binding must be reassigned (counters, accumulators). Never use var in new code. Note that const prevents reassignment of the binding, not mutation of an object it refers to.


Naming conventions: camelCase for variables and functions (unitPrice), UPPER_SNAKE_CASE for true constants (VAT_RATE), PascalCase for classes. Names must be descriptive: monthlyPayment, not mp or x.

Type inspector


Type any JavaScript expression: the inspector evaluates it and reports its type and its conversions to boolean, number and string.











Implicit conversion (coercion)


Operators convert their operands when the types differ. The binary + performs concatenation as soon as one operand is a string; the other arithmetic operators (- * / %) convert to number. In a condition, every value is converted to boolean. Exactly eight values are falsy: false, 0, -0, 0n, "", null, undefined and NaN; every other value, including "0" and [], is truthy.


Explicit conversion is always preferable: Number("12.5"), parseInt("250 DZD", 10), String(42), Boolean(x). Values read from form fields are always strings and must be converted before any arithmetic.









04
OperatorsArithmetic, comparison, logical




Arithmetic and assignment


+ - * /, % (remainder), ** (exponent), increment ++, and compound assignment +=, -=, *=. Precedence follows mathematical conventions; use parentheses whenever it improves readability.


Logical operators


&&, ||, !. The first two short-circuit and return one of their operands, not necessarily a boolean. The nullish coalescing operator ?? substitutes a default only for null or undefined, unlike ||, which also replaces 0 and "". The ternary cond ? a : b is an expression.






Equality: loose versus strict


The loose equality == applies type coercion before comparing, with rules that are hard to memorise; the strict equality === compares type and value without conversion. Switch the matrix between the two operators and hover over a cell: T marks a true comparison.






Hover over a cell


RuleAlways use === and !==. Note also that NaN is not equal to itself: test it with Number.isNaN(x).

Conditional Executionif, else if, switch, ternary




A conditional statement evaluates a boolean expression and executes one branch. Conditions should be ordered from the most specific to the most general, since the first satisfied branch wins.

switchcompares a value with several constant cases using strict equality. Each case must end with break (or return), otherwise execution falls through to the next case, a classic source of bugs.





06
Loopsfor, while, do...while, for...of






LoopWhen to use it


for (init; cond; step)A known number of iterations (12 months, 10 instalments)


while (cond)An unknown number of iterations, condition tested first (until a target is reached)


do { } while (cond)At least one execution guaranteed (input validation)


for (const x of list)Iterating over the elements of an array or string




break leaves the loop immediately; continue skips to the next iteration. Every loop must have a reachable termination condition: an infinite loop freezes the page, since JavaScript in the browser runs on a single thread.

EX 01
Invoice calculator
Foundational


Declare the unit price (2 750 DZD) and quantity (6) of an item and the VAT rate (19%). Compute the net amount, the VAT and the gross amount, rounded to two decimals, and display them on three lines using template literals, for example Net amount: 16500.00 DZD. Use const wherever possible.






EX 02
Discount tiers and delivery zones
Intermediate


An online shop applies a discount of 10% from 100 000 DZD, 5% from 50 000 DZD, and none below. Delivery costs depend on the zone: "north" 400 DZD, "highlands" 600 DZD, "south" 900 DZD, otherwise 1 000 DZD; delivery is free when the discounted amount exceeds 80 000 DZD. Write the logic with if...else and switch, and test it on three orders.






EX 03
Savings simulation
Intermediate


A student deposits 5 000 DZD at the beginning of each month into an account remunerated at 6% per year (0.5% per month, compounded monthly). Using a while loop, determine after how many months the balance reaches 100 000 DZD, and display the balance every 6 months.

A console loan simulator

  • Constants: principal P = 1 200 000 DZD, annual rate 7%, duration 5 years. Compute the monthly rate r and the number of instalments n.

  • Monthly instalment by the annuity formula: M = P × r / (1 − (1 + r) ** −n).
